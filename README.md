# Wander Wisdom

Landing page for **Wander Wisdom**, the co-creation travel journal by Anna Mussotter.
Plain HTML, CSS and JavaScript: no build step, no dependencies, no cookies.

## Files

| File | What it is |
|---|---|
| `index.html` | The page: map, story, what's inside, order section |
| `entries.js` | **The people on the map.** Edit this to add your real entries |
| `script.js` | Map camera, journal-page card, prompts, order button (checkout link at the top) |
| `styles.css` | All styling. Colours and fonts are at the top under `:root` |
| `assets/map-dots.js` | The dot-grid world map (generated by `tools/build-map.mjs`) |
| `assets/fonts/` | Self-hosted fonts (no Google Fonts requests, better for GDPR) |
| `wander-wisdom-book/` | Book text (`BOOK.md`) and page images shown on the site |
| `impressum.html`, `datenschutz.html`, `widerruf.html` | Legal placeholder pages, **fill in before going live** |
| `BRIEF.md` | Content brief and copy |

## Run it locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000. (Opening `index.html` directly also works, but some
browsers block local fonts that way.)

## Replace the example entries

Open `entries.js`. Each person has a place, coordinates, first name, hometown, the
question and their answer. Set `example: false` (or delete the line) for real entries,
and the "Example entry" stamp disappears. The order of the list is the order of the
journey line. Only publish entries with the person's permission.

## Connect checkout

At the top of `script.js`, paste your checkout link (Stripe Payment Link, Shopify,
Etsy, PayPal …) into `CHECKOUT_URL`. Until then the order button tells visitors to
order via Instagram.

## Deploy on Vercel

1. Go to vercel.com, sign in with GitHub, click **Add New → Project**.
2. Pick the `Wander-wisdom-` repository. Framework preset: **Other**. No build command.
3. Click **Deploy**. Every push to the selected branch updates the site.

## Before going live

- Fill in Impressum, Datenschutz and Widerrufsbelehrung.
- Replace the five example entries with real ones.
- Add the checkout link.
